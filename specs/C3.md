# Task C3 — world rendering: scene rig + map renderer
Owns (exclusive): `client/src/render/scene.ts`, `client/src/render/mapRenderer.ts`
Depends on: contract only.

Read first: CONTRACT.md (RULES + C3 module table + deco prop model sheets), STYLE_BIBLE.md,
shared/src/maps/types.ts, shared/src/maps/dustbowl.ts, client/src/contract/visual.ts, shared/src/rng.ts.

Implement per the frozen export table:
- scene.ts SceneRig: WebGLRenderer (antialias, ACESFilmicToneMapping, SRGBColorSpace, PCFSoft
  shadowmap, pixelRatio min(dpr,2), powerPreference high-performance); PerspectiveCamera(BASE_FOV).
  setTheme: hemisphere light (theme.sky/theme.ground, hemiIntensity), directional sun
  (theme.sunColor/Intensity, position = -sunDir × 60, castShadow, 2048 shadow map, ortho frustum
  fitted to ±40), FogExp2(theme.fog, fogDensity), clear color theme.sky. applyCamera: set pos/rotation
  (YXZ order: yaw then pitch) + fov with updateProjectionMatrix + decaying shake offset (rotational
  noise, trauma^2 scaled, ≤0.02 rad). shake(amount) adds trauma (clamp 0..1). resize/render/dispose.
  Guard WebGL context creation failure: show a readable div and throw a caught error.
- mapRenderer.ts buildMap(map): returns { root, solids } — solids = map.boxes.map(boxToAABB).
  MAT_COLORS per STYLE_BIBLE.md mapping. Ground: plane sizeX+8 × sizeZ+8, MAT_COLORS[floorMat],
  receiveShadow, y=-0.01. Sky dome: sphere r=400, BackSide MeshBasicMaterial with fog:false and
  vertex-color gradient theme.sky (top) → theme.horizon (bottom) — set vertex colors manually (raw
  BufferGeometry permitted for the dome as a factory exception). Boxes: box()
  mesh per BoxDef at exact coords, MAT_COLORS[mat], castShadow+receiveShadow, then bake() into the
  static group. Deco: for each DecoZone, scatter count props via rng(decoSeed(map.id, zoneIndex)):
  random point in rect, reject if < minSpacing to a placed prop, inside any solid (point vs AABB
  inflated 0.5), or < 2.5m from any spawn; build via the prop factories in CONTRACT.md (crate,
  barrel, pallet, pipe, rock, shrub, cactus, snowRock, plant, paperStack — 3–10 prims each, all
  PALETTE colors, slight rng rotation/scale jitter); bake everything into the same static group.

Draw-call budget: the whole map+deco must bake to ≤ ~20 draw calls (one per material).
Definition of done: `npm run typecheck` passes; no stubs.
Return: summary, files touched, baked draw-call count for dustbowl, typecheck output. NOT file contents.
