# P9_ORBIT — solo score-attack dodge flier (showcase #1)

**Owns (only):** `games/orbit/**` (create all: package.json ×3? NO — single workspace pattern:
one `games/orbit/client` package is NOT needed; follow the SMALL-GAME shape: one workspace
`games/orbit` with `src/`, serving via platform registry GameModule with clientDist pointing to
its vite build)
**Contract:** docs/PLATFORM.md §7 · @platform/sdk + @platform/engine ONLY for platform needs
· house bibles for style.

## Envelope
Single-player, offline-capable arcade run: pilot a ship down an endless tunnel of debris
rings; steer left/right/up/down; near-misses score, hits end the run. 60fps feel, 30Hz logic
is fine. No room/lobby — play button starts immediately.

## Rules
- Speed ramps 18→42 u/s over a 3-minute difficulty curve (seeded per run, rng from shared).
- Debris: rotating low-poly rocks + spinning laser hoops; spawn ahead, recycle behind.
- NEAR MISS: passing within 1.2u of debris without contact = +combo; combo decays after 2s.
- Score = distance×1 + nearMisses×25×combo multiplier. Hit → explosion, run ends.
- One shield pickup per ~20s: absorbs one hit.

## Platform integration (the point of this game — USE THE SDK)
- `createGameClient({gameId:'orbit', canvas})`; engine SceneRig+Loop+prims+bake+Pools+ChaseCam.
- On run end: `saves.put('best', rev, {score, dist, date})` via updateSave merge (keep max);
  on boot read 'best' → menu shows personal best; ALSO auto-save resume state every 5s to
  slot 'resume' {seed, dist, score} so a reload offers CONTINUE (only if score>0).
- Stats via server only when in a sessionless context — SKIP ws entirely; profile optional
  (name display). If authenticated (profile.me()), report nothing here (no rooms).
- Pads: physical gamepad via input hub (left stick steer, A = boost); declare padLayout
  `{sticks:[{id:'l',label:'steer'}], buttons:[{bit:0,label:'BOOST'}]}` so /pad works too.
- Audio: SynthKit voices + custom sfx() recipes for whoosh/nearmiss ping/shield.

## Look
Flat-shaded low-poly; palette: deep space ink bg, neon cyan ship trail, amber debris, magenta
hoops; fog for depth; particle bursts on near-miss/hit; subtle camera roll on steer.
