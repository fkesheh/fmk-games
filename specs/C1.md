# Task C1 — client networking: connection, interpolation, prediction
Owns (exclusive): `client/src/net/connection.ts`, `client/src/net/interpolation.ts`,
`client/src/net/prediction.ts`
Depends on: contract only.

Read first: CONTRACT.md (RULES + C1 module table + conventions), shared/src/types.ts, config.ts,
physics.ts (stepBody — prediction MUST use the same code path as the server), protocol.ts.

Implement per the frozen export table:
- connection.ts: WebSocket wrapper; default url = `${location.protocol === 'https:' ? 'wss' : 'ws'}://${location.host}/ws`;
  app-level ping every NET.pingEveryMs; smoothed pingMs (EMA α=0.2); serverOffsetMs via the frozen
  formula (CONTRACT.md C1 table): offset = pong.serverTime + rtt/2 − performance.now(), keeping the
  sample with the lowest RTT seen; decode via decodeS2C, drop nulls; send via encodeC2S;
  reconnect is NOT automatic — call onClose once. Connect resolves on open, rejects on error/timeout (5s).
- interpolation.ts: keeps ~1s of (serverTime, players) snapshots; sample(renderServerTime) lerps
  between bracketing snapshots (position + yaw + pitch; shortest-angle lerp for yaw; discrete fields
  from the newer snapshot); extrapolate position only up to NET.interpMaxExtrapolateMs using the two
  latest snapshots' velocity; snap (no lerp) when teleport > 10m; players present in only one
  snapshot appear/disappear immediately.
- prediction.ts: stores pending inputs (cap 120); pushInput applies stepBody(TICK_DT) with speedMul
  and stores; reconcile sets authoritative x/y/z/height/vy (vy from YouSnap.vy, so gravity replays
  correctly mid-jump) then replays inputs with seq > ackSeq (and drops older); snap when correction
  distance > 1m else blend (the class applies corrected state directly; smoothness is the caller's
  concern — expose nothing extra).

No per-frame allocation in sample/pushInput hot paths beyond small temporaries.
Definition of done: `npm run typecheck` passes; no stubs.
Return: summary, files touched, typecheck output, risks. NOT file contents.
