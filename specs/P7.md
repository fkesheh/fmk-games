# P7_SDK_INPUT_AUDIO — input hub, synth kit, pad overlay

**Owns (only):** `platform/sdk/src/{input.ts, audio.ts, padQr.ts, input.test.ts}` (+ your
re-exports in `src/index.ts`)
**Contract:** `types.ts` (frozen) · docs/PLATFORM.md §4.4/§4.5.

## Mission
- **input.ts** — GameInputHub: merge sources into ONE stable InputFrame object.
  - Keyboard: DEFAULT_KEY_BINDINGS (WASD/arrows + 4 action bits); blur clears all held state.
  - Gamepad API: poll navigator.getGamepads() in frame(); standard mapping; deadzone;
    left stick → moveX/moveZ; right stick accumulates lookDX/lookDY at lookSpeedRadPerSec·dt
    (frame() computes dt internally from last call); buttonMap → bits; edges queue press/release.
  - Touch (setTouch): on-screen virtual stick (left half) + action buttons overlay divs;
    pointer events; only when enabled AND coarse pointer.
  - requestPointerLock(): canvas.requestPointerLock with promise + unadjustedMovement if
    available; mousemove deltas → lookDX/DY accumulation (sensitivity const 0.0022 rad/px).
  - edges() drains once; frame() returns the same mutated object every call.
- **audio.ts** — SynthKit: lazy AudioContext (resume on first gesture); voices click/deny/
  jump/land/hit/explode/pickup/score/win/lose — each a distinct recipe (osc type+pitch env,
  noise burst for explode/hit); dist falloff: vol×(1 − clamp((d−10)/35)) when d!=null;
  ambient(kind) loops filtered noise (wind) / low sine hum; switching kinds crossfades; 'off' stops.
- **padQr.ts** — showPadPairing(urlPath, code): fixed bottom-right card, big monospace code,
  URL text, "on your phone open <url> and enter this code"; setCode/bound/dismiss per interface.

## Tests
input.test.ts: fake keyboard events + fake gamepad object array → merged frame values,
deadzone, edge drain semantics, blur reset. DOM-free where possible (drive handlers directly).

## Rules
Strict TS; no new deps; no samples/assets. Gate: typecheck + tests green.
