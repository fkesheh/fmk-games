# Task C7 — synthesized audio engine
Owns (exclusive): `client/src/audio/audio.ts`
Depends on: contract only.

Read first: CONTRACT.md (RULES + C7 module table), DESIGN_BIBLE.md (weapon roles — sounds must read
as their weapon at distance).

Implement AudioEngine per the frozen export table, fully synthesized WebAudio (no assets):
- Lazy AudioContext creation in resume() (called on first user gesture); every method is a safe
  no-op before that. Master gain 0.5 → destination.
- Shared noise buffer (1s white noise) reused by all noise-based sounds.
- Distinct recipes per SfxKind: shot_pistol (sharp crack: noise burst 80ms + 800Hz osc ping, fast
  decay), shot_smg (short pop 60ms, higher), shot_rifle (heavy crack 120ms + low thump), shot_sniper
  (boom 300ms, lowpass sweep 3k→200Hz), shot_shotgun (wide boom 200ms, bandpass ~500Hz), shot_knife
  (whoosh: bandpass noise sweep), reload (2 clicks + slide: short filtered noise ticks), hit (1.2kHz
  tick 40ms), headshot (1.8kHz ding 80ms), death (low thud 150ms), footstep (soft noise tap 40ms,
  alternate two slight variants), round_start (two-note chime), round_end (low resolve note), buy
  (cash blip 1kHz), deny (buzz 180Hz), win (rising 3-note), lose (falling 2-note), click (UI tick).
- sfx(kind, {dist, vol}): gain = vol ?? 1; dist attenuates linearly 1 at ≤10m → 0 at 45m.
- ambient(outdoor): looping filtered noise — wind (bandpass ~400Hz, slow LFO on gain) outdoor, low
  hum (120Hz osc + noise, very quiet) indoor; crossfade 0.5s on switch; null/stop on menu.
- Keep it subtle: no clipping, shot sounds capped at 0.8 gain.

Definition of done: `npm run typecheck` passes; no stubs; no audio asset files.
Return: summary, files touched, typecheck output, risks. NOT file contents.
