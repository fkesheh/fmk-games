# P11_GHOSTRUN — time-trial vs your saved ghost (showcase #3)

**Owns (only):** `games/ghostrun/**` (single workspace `@ghostrun/game`, same small-game shape
as P9_ORBIT)
**Contract:** docs/PLATFORM.md §7 · @platform/sdk+engine ONLY.

## Envelope
Solo sprint over a floating procedural track (gaps, ramps, moving blocks). Beat the clock;
your best run replays as a translucent ghost alongside you. No rooms; offline-capable.

## Rules
- Track: seeded spline of 40 platforms (rng(seed)); seed changes daily via date hash —
  "today's run". Fall = respawn at last checkpoint (+1s penalty). Timer counts up.
- Movement: run 10 u/s, jump v=8.5/g−22, coyote-time 0.12s, air control 0.6.
- Checkpoints every 8 platforms; finish pad ends the run → results screen.

## Ghost + saves (THE point)
- During a run record [t, x, y, z, yaw] every 100ms (Float32-ish arrays in a plain object).
- On finish better than saved best: `updateSave('ghost', merge)` slot stores
  {date, timeMs, samples} ≤ SAVES.maxBytes (quantize to 2 decimals; ~40KB for a 3-min run).
- Menu: personal best time + GHOST RACE toggle; during play interpolate ghost pose by t and
  render translucent cyan capsule; beat-your-ghost confetti burst at finish.
- Slot 'best' {timeMs, date} mirrors for fast menu load. Handle missing/corrupt saves
  gracefully (fresh start).

## Platform integration
SDK facade (gameId 'ghostrun'); engine rig/loop/prims/pools/fpsCam+OrbitCam(menu); physical
pads: left stick move, A jump; padLayout {sticks:[{id:'l',label:'move'}],
buttons:[{bit:0,label:'JUMP'}]}. SynthKit: footstep ticks, jump/land, checkpoint chime,
finish fanfare. Profile name shown on the results card when authenticated.

## Look
Sunset gradient sky dome (vertex colors), amber platforms with ink sides, teal ghost, white
finish flag; long shadows; speed lines particles when airborne >0.5s.
