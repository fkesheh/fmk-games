# P6_SDK_CORE — @platform/sdk services + facade

**Owns (only):** `platform/sdk/src/{net.ts, rooms.ts, profile.ts, saves.ts, client.ts,
saves.test.ts}` (+ your re-exports in `src/index.ts`)
**Contract:** `types.ts` (frozen) · docs/PLATFORM.md §4.1/§4.2/§4.5.

## Mission
Client glue every new game imports instead of hand-rolling: connection, lobby senders,
profile/auth, cloud saves, and the `createGameClient()` facade.

- **net.ts** — ws wrapper: connect resolves on open; auto-reconnect (exp backoff 0.5→8s,
  reset on clean open) replaying `{t:'auth'}` when a token exists; app-level ping/pong
  every NET.pingEveryMs for pingMs() EMA(α=0.2); serverNow() = performance.now()+offset with
  min-RTT sample filter (STRICKEN formula: pong.serverTime + rtt/2 − now). send() no-ops
  when closed; onClose(clean) fires once per drop.
- **rooms.ts** — RoomsApi = typed senders over LobbyC2S verbs ONLY (no fake promises;
  replies arrive via net.onMessage). Include resume/sig from identity automatically.
- **profile.ts** — token cache under 'play.auth' (try/catch'd localStorage, identity.ts
  precedent); ensureDeviceAuth(): POST /api/auth/device {sig: identity.sig()} → store token,
  update cached me(); rename/claimCode/claim similar REST calls; me() hydrates from auth_ok
  pushed by net when autoAuth sends the stored token after connect.
- **saves.ts** — CloudSaves implements SavesApi via REST with Bearer token; PUT conflict →
  resolve {ok:false, record:current}; network failure THROWS. updateSave() helper: get→merge→
  put, one retry on conflict using merged data.
- **client.ts** — createGameClient(): builds SdkNet+Rooms+Profiles+Saves(gameId)+GameInputHub+
  SynthKit; ready resolves after first connect attempt settles AND identity loaded; wires
  net.onMessage → profile auth_ok handling; showPadPairing() runs pad_pair_request flow and
  renders padQr overlay, listening for pad_status; dispose() closes everything cleanly.

## Tests (saves.test.ts)
