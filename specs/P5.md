**Owns (only):** `platform/engine/src/{loop.ts, rig.ts, prims.ts, pools.ts, cameras.ts,
debugHud.ts, loop.test.ts}` (+ append your own re-exports to `src/index.ts` — you are the

**Contract:** `types.ts` (frozen) · docs/PLATFORM.md §4.6.

## Mission
The shared three.js toolkit every new game builds on. Reference implementations exist in the
repo — READ and generalize, don't reinvent:
- rig ≈ `games/fps/client/src/render/scene.ts` (ACESFilmic, SRGB, PCFSoft shadows, FogExp2)
- prims/bake ≈ `games/fps/client/src/contract/visual.ts` factory vocabulary
- loop: fixed-step accumulator; catch-up clamp; alpha for interp.

## Per-file bar
- **loop.ts**: rAF-driven; onTick(dt=1/tickHz const, tick#) possibly N× per frame; onRender
  once per rAF with clamped dtFrame + alpha. stop() cancels rAF; start() resets tickCount.
  Wrap callbacks in try/catch: log once + stop on repeated throws (never spam-console).
  Test with fake rAF (inject via constructor param `raf?: (cb)=>void` — ADD this optional
  param, it's additive).
- **rig.ts**: opts defaults per types.ts; shadowMapSize 0 = disabled; setSun positions a
  directional light at dir*100 tracking focus() target with ortho frustum ±shadowExtent;
  hemisphere from groundColor/hemiIntensity. resize() reads canvas clientWidth/Height.
- **prims.ts**: geometry caches keyed by dims (reuse BufferGeometry), material cache keyed by
  MatSpec JSON; bake() merges static meshes per material using BufferGeometryUtils.mergeGeometries.
- **pools.ts**: preallocated InstancedMesh or Points; burst/spawn recycle oldest when full;
  update(dt) advances in place. Zero allocations after construction in update paths.
- **cameras.ts / debugHud.ts**: small, obvious, test the math where cheap.

## Tests
loop.test.ts: deterministic virtual clock — N ticks at right cadence, alpha correctness,
catch-up clamp stops spiral, stop() halts, throw-stops-after-repeats. Pools: recycling bounds.
