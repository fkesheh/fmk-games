- clientGame.ts ClientGame per the frozen export table. Full wiring:
  - join flows: create Connection, on welcome/joined build the world: buildMap(MAPS[mapId]) into a
    fresh SceneRig theme, Predictor with solids, InterpBuffer reset; roster from 'joined'. Call
    menus.showJoining() when a join starts; on 'joined' → menus.hideAll() + menus.showInRoom(map

  - input loop (frame()): every rAF sample InputController; at TICK_RATE send input {seq, moveX,

    predicted eye pos with input yaw/pitch; fov BASE_FOV or zoomFov when scoped+sniper.
  - snapshots: interp.push; predictor.reconcile(self snap + ack); you → ClientState; roster
    updates on joined/left events.
  - remotes: sample(interp at serverNow − NET.interpDelayMs) → PlayerModels.sync (merge roster

  - `shot` events (broadcast for EVERY shot volley, self included): effects.tracer(from, to),
    impact particles at `to`, audio sfx('shot_' + weapon, {dist}) with dist from your camera; when
    shooterId ≠ you also PlayerModels.muzzle(shooterId); when shooterId = you: viewmodel.fire() +
    shake(0.1). Blood comes from 'hit' (your shots) and 'kill' events, not from `shot`.
  - freeze-phase prediction gate: during 'freeze'/'roundEnd'/'matchEnd' still SEND inputs but do not
    advance the local predicted body (the server doesn't move players either) — zero rubber-banding
    at round start.
  - events: kill → killfeed + death burst + death sound; MULTIKILL → hud.banner(countLabel + ' — ' +
    playerName) (labels: 2 'DOUBLE KILL', 3 'TRIPLE KILL', 4 'QUAD KILL', 5+ 'ACE') +
    audio.sfx('multikill'); hit → hitmarker + hit/headshot sound +
    tracer to victim; dmg_taken → damageFrom(yaw − ownYaw) + shake(0.3) + blood at own position is
    skipped (first person) → red edge flash via hud.damageFrom; round_start → banner + auto-open buy

    showMatchEnd (with current roster) + win/lose sound — dismissed when a later snapshot shows
    phase 'warmup' (menus.hideAll + showInRoom); halftime → REPLACE the local roster (and your own
    team) from the event's roster + banner "HALFTIME — SIDES SWAPPED"; buy_result ok →
    re-open buy menu with fresh state + buy sound, fail → deny sound; player_joined/left → roster.
  - edges: reload → send + viewmodel.reload; slot n → map to owned weapons (WEAPON_ORDER index) →
    send switch + viewmodel.setWeapon optimistic; buy → toggle buy menu (only when canBuy);

  - warmup death: show nothing special; respawnAt countdown small text.
  - footsteps: own + others when moving and onGround, every 0.38s at speedRun, dist-attenuated.
  - leave(): close connection, dispose scene, back to main menu via menus.
  - Robustness: onClose → menus.showMain('Connection lost'); every message handler wrapped so one
