# Task S1 — server transport + lobby + entry
Owns (exclusive): `server/src/net.ts`, `server/src/rooms.ts`, `server/src/index.ts`
Depends on: contract only.

Read first: CONTRACT.md (RULES + server module table S1 sections + types.ts/config.ts in shared/src).

Implement the three files exactly per the frozen export table:
- `net.ts`: Session + NetServer over `ws`, parseC2S validation at the door (drop invalid),
  ws protocol-level ping/pong every NET.pingEveryMs recording per-session rttMs, http server that
  serves staticDir with content types (html/js/css/json/png/ico) + SPA fallback to index.html when
  staticDir is provided, WebSocketServer on path `/ws` on the same http server. Assign 8-char
  session ids (crypto.randomUUID slice).
- `rooms.ts`: Lobby per contract — public quick_join matching (prefer warmup rooms with space,
  else create with a random map), create_private/join_private with 5-char [A-Z0-9] codes, room_full /
  no_room error messages, list_rooms (public only), leave, routing of input/reload/switch/buy to the
  session's room, disconnect cleanup, empty-room reaping (private immediately, public after 30s),
  MAX_ROOMS guard. Imports GameRoom from './game.js' (allowed per contract module table).
- `index.ts`: entry — PORT env ?? 8080; staticDir = client dist if it exists on disk (check a few
  candidate paths: ../client/dist relative to cwd and to import.meta.url), else null; wire
  NetServer↔Lobby; every 1s poll rooms' stalePlayers() and close those sockets; handle SIGTERM
  gracefully. Wrap per-socket message handling in try/catch — a throwing handler must not kill
  the process.

Definition of done: `npm run typecheck` passes; `node --import tsx server/src/index.ts` (or the dev
script) starts and answers an HTTP request; no stubs.
Return: summary, files touched, typecheck output, risks. NOT file contents.
