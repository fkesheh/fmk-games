# P2_SRV_DB — storage layer

**Owns (only):** `platform/server/src/services/{db.ts, db.test.ts}`
**Contract:** `db.ts` class skeleton + row interfaces (FROZEN signatures), limits in
`platform/shared/src/limits.ts`.

## Mission
`node:sqlite` (Node 24 builtin, `import { DatabaseSync } from 'node:sqlite'`) behind `Store`.
WAL on. Schema v1 in a `schema_migrations` table; migrate inside the constructor.

```
profiles(id TEXT PK, name TEXT NOT NULL, created_at INTEGER NOT NULL)
auth_identities(sig TEXT PK, profile_id TEXT NOT NULL REFERENCES profiles(id))
tokens(token TEXT PK, profile_id TEXT NOT NULL REFERENCES profiles(id), created_at INTEGER)
claim_codes(code TEXT PK, profile_id TEXT NOT NULL, expires_at INTEGER NOT NULL, used INTEGER NOT NULL DEFAULT 0)
saves(profile_id TEXT, game_id TEXT, slot TEXT, rev INTEGER NOT NULL, data TEXT NOT NULL,
      size INTEGER NOT NULL, updated_at INTEGER NOT NULL,
      PRIMARY KEY(profile_id, game_id, slot))
stats(profile_id TEXT, game_id TEXT, key TEXT, value REAL NOT NULL,
      PRIMARY KEY(profile_id, game_id, key))
```

## Behavior
- Constructor: `new DatabaseSync(dbPath)`; ANY throw → in-memory mode (`:memory:` equivalent:
  just keep JS Maps) and set `degraded = true`. Never rethrow from constructor.
- ids: `crypto.randomUUID()`; tokens: 32 random bytes base64url (`AUTH.tokenBytes`).
- Claim codes: 6 chars from `CLAIM_ALPHABET`, expiry `AUTH.claimTtlMs`; consume = used=1.
- `putSave`: transactional compare-and-set on rev (expectedRev must equal current, missing
  slot counts as rev -1... frozen: current rev of absent slot is **0**? NO — absent = expectedRev
  **must be 0** and first write sets rev 1). Enforce SAVES.maxBytes/size and maxSlots count →
  return 'quota' / 'slots_full'.
- `addStats`: upsert value += delta[k] (clamp |value| to STATS.maxValue).
- All statements prepared once in ctor. Sync methods only.

## Tests
In-memory mode exercises every method: profile create/reuse, token mint+resolve, claim
mint/consume/expiry/second-use-rejected, save CAS happy/conflict/quota/slots-full/delete,
stats accumulate + clamp, degraded flag after pointing at an unwritable path (e.g. `/dev/null/x.db`).
