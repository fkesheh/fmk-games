# P10_SUMO — 2–8p arena knockout (showcase #2)

**Owns (only):** `games/sumo/**` (workspace `@sumo/{shared,server,client}` like kart/bank shape)
**Contract:** docs/PLATFORM.md §7 · GameModule v2 · @platform/sdk+engine for the client
· server follows platform/server patterns (plain TS module, no entry point).

## Envelope
2–8 players on a shrinking circular platform floating in space. Push everyone off. Last one
standing takes the round; first to 3 round wins takes the match. Public quick-join + private
codes via the standard lobby verbs; bots fill to ≥2 when alone.

## Rules (server-authoritative, 30Hz)
- Movement: accel 40 u/s², friction 6/s, max speed 9 u/s. Radius 0.6 cylinder bodies.
- DASH: bit-0 press → impulse 18 u/s along move dir, 1.5s cooldown, brief afterimage.
- JUMP: bit-1 → vy 8, gravity −22; airborne players can't dash.
- Player-vs-player: elastic circle pushout (momentum transfer weighted by relative speed —
  a dashing shover launches a standing shovee).
- Platform radius shrinks 14→4 u over 45s per round; outside edge = falling (y<−12 = out).
- Knockouts broadcast killfeed-style events; round ends when ≤1 remains (or timer → most
  centered wins... frozen: survivor; if none, draw).

## Stats (v2 proof)
On round end, winner's room calls `io.reportStats(winnerId, {'sumo.win':1})`; every KO:
`{'sumo.ko':1}` credited to the last pusher within 3s (else 'sumo.self':1). Anonymous no-op.

## Pads
padLayout: sticks [{id:'l',label:'move'}], buttons [{bit:0,label:'DASH'},{bit:1,label:'JUMP'}].
Pad sessions deliver pad_input as their own session id — room resolves seat via io.padOwner()
and applies the frame to that player each tick.

## Client
SDK facade + engine rig/loop/prims/pools/ChaseCam(orbit-ish top-down 55°); prediction NOT
required (slow game) — send inputs at 30Hz, render interpolated snapshots (120ms interp,
reuse the InterpBuffer pattern from fps net/interpolation.ts conceptually, implement small).
HUD: round timer, platform radius ring warning, cooldown pips, alive count, scoreboard Tab.
SynthKit audio: thud on bump, whoosh dash, splash-out fall, round stingers.

## Look
Flat-shaded: candy-red vs sky-blue vs lime vs amber player capsules with nameplates; slate
platform with grid texture via vertex colors; starfield points bg; rim highlight on shrink.
